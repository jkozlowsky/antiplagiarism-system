Każda z kolejnych funkcji realizującej dany przyapdek użycia korzysta z wywołania wyżej opisanej funkcji w celu wysłania odpowiedniego powiadomienia. W celu wysłania komunikatu przykładowo w wersji angielskiej, wartości zostaną pobrane z pliku messages_en.properties.

`AccountService` i implementacja przypadku użycia oraz wywołanie funkcji do wysyłania powiadomienia mailowego

```java
@MethodCallLogged
    @PreAuthorize("hasAuthority(T(pl.lodz.p.it.ssbd2026.ssbd01.config.consts.AccountConsts).ROLE_ADMIN)")
    @Retryable(retryFor = ConcurrentUpdateException.class)
    @Transactional(propagation = Propagation.REQUIRES_NEW, transactionManager = "mokTransactionManager")
    public void blockUserAccount(UUID id, String versionHash) {
        Account account = accountRepository.findById(id).orElseThrow(AccountNotFoundException::new);

        mokRefreshRepository.refresh(account);
        if (!versionHash.equals(versionHashService.hashObjectVersion(id, account.getVersion()))) {
            throw new ConcurrentUpdateException();
        }

        if (account.getIsBlocked()) {
            throw new AccountIsBlockedException();
        }

        account.setIsBlocked(true);
        accountRepository.saveAndFlush(account);
        postCommitTransactionManager.register(() ->
                emailService.sendAccountIsBlockedInfo(account.getEmail(), account.getLogin(), account.getLanguageVersion().getLanguage()));
    }
```

`AccountScheduler` wywołanie funkcji do wysyłania powiadomień mailowych.

```java
@Scheduled(fixedDelayString = "${app.scheduler.check.interval.ms}")  
@Transactional(transactionManager = "mokTransactionManager")  
public void processInactiveAccounts() {  
    LocalDateTime now = LocalDateTime.now();  
    int reminderHours = expirationHours / 2;  
  
    accountRepository.findAllByIsVerifiedFalseAndSecondEmailSentFalseAndCreationDateBefore(now.minusHours(reminderHours))  
            .forEach(acc -> {  
                String lang = acc.getLanguageVersion().getLanguage();  
                emailService.sendActivationReminderEmail(acc.getEmail(), acc.getActivationToken(), lang);  
                acc.setSecondEmailSent(true);  
            });  
  
    accountRepository.findAllByIsVerifiedFalseAndCreationDateBefore(now.minusHours(expirationHours))  
            .forEach(acc -> {  
                String lang = acc.getLanguageVersion().getLanguage();  
                emailService.sendAccountDeletedEmail(acc.getEmail(), lang);  
                accountRepository.delete(acc);  
            });  
}
```

Z uwagi na internacjonalizację, komunikaty w języku polskim są zdefiniowane następująco:
W klasie Translator która jest komponentem utworzono metodę `translateForUser`, która oprócz klucza do zinternacjonalizowanego komunikatu przyjmuje jako parametr kod wersji językowej. Po czym przekształca komunikat na zinternacjonalizowany odpowiednio do przekazanego kodu wersji językowej. 

```java
@Component  
@RequiredArgsConstructor  
public class Translator {  
  
    private final MessageSource messageSource;  
  
    public String translate(String key) {  
        return messageSource.getMessage(key, null, LocaleContextHolder.getLocale());  
    }  
  
    public String translate(String key, Object... args) {  
        return messageSource.getMessage(key, args, LocaleContextHolder.getLocale());  
    }  
  
    public String translateForUser(String key, String langCode, Object... args) {  
        Locale locale = (langCode != null) ? Locale.of(langCode.toLowerCase()) : Locale.ENGLISH;  
        return messageSource.getMessage(key, args, locale);  
    }  
}
```
