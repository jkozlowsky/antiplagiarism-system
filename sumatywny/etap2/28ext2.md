Każde wysłanie powiadomienia e-mail rozpoczyna się od bazowej funkcji `sendEmail`:

```java
 public void sendEmail(String toAddress, String subject, String content) {
        SimpleMailMessage message = new SimpleMailMessage();
        message.setFrom("ssbd01.2026@gmail.com");
        message.setTo(toAddress);
        message.setSubject(subject);
        message.setText(content);

        mailSender.send(message);
    }
```

Każda z kolejnych funkcji realizującej dany przyapdek użycia korzysta z wywołania wyżej opisanej funkcji w celu wysłania odpowiedniego powiadomienia. W celu wysłania powiadomienia w odpowiedniej wersji językowej zdefiniowane są pliki properties np. messages_pl.properties, gdzie zawarte są komunikaty powiadomień. W celu wysłania komunikatu przykładowo w wersji angielskiej, wartości zostaną pobrane z pliku messages_en.properties.


### Przykład mechanizm wysyłania powiadomienia e-mail w przypadku akcji inicjowanej przez użytkownika - MOK.4 Zablokuj konto użytkownika

`EmailService` i implementacja wysłania powiadomienia o zablokowaniu konta
```java
 public void sendAccountIsBlockedInfo(String toAddress, String login, String langCode) {
        String subject = translator.translateForUser("email.account.blocked.subject", langCode);
        String content = translator.translateForUser("email.account.blocked.content", langCode, login);
```

Z uwagi na internacjonalizację, komunikaty w języku polskim są zdefiniowane następująco:

```bash
email.account.blocked.subject=Powiadomienie - Twoje konto zostało zablokowane
email.account.blocked.content=Witaj {0},\n\nTwoje konto zostało zablokowane. Aby uzyskać więcej informacji, skontaktuj się z administratorem.
```

`AccountService` i implementacja przypadku użycia oraz wywołanie funkcji do wysyłania powiadomienia mailowego

```java
@MethodCallLogged
    @PreAuthorize("hasAuthority(T(pl.lodz.p.it.ssbd2026.ssbd01.config.consts.AccountConsts).ROLE_ADMIN)")
    @Retryable(retryFor = ConcurrentUpdateException.class)
    @Transactional(propagation = Propagation.REQUIRES_NEW, transactionManager = "mokTransactionManager")
    public void blockUserAccount(UUID id, String versionHash) {
        Account account = accountRepository.findById(id).orElseThrow(AccountNotFoundException::new);

        mokRefreshRepository.refresh(account);
        if (!versionHash.equals(versionHashService.hashObjectVersion(id, account.getVersion()))) {
            throw new ConcurrentUpdateException();
        }

        if (account.getIsBlocked()) {
            throw new AccountIsBlockedException();
        }

        account.setIsBlocked(true);
        accountRepository.saveAndFlush(account);
        postCommitTransactionManager.register(() ->
                emailService.sendAccountIsBlockedInfo(account.getEmail(), account.getLogin(), account.getLanguageVersion().getLanguage()));
    }
```
